Binomio de Newton
Teorema: Se x e a são numeros reais e n é um numero inteiro positivo, então
    (x+a)**n = n Somatorio k=0 (Combinação n por k) (a**k)(x**n-k)
Observe que:
 1) O desenvolvimento de (x+a)**n possui n+1 termos.
 2) Os coeficientes do desenvolvimento de (x+a)**n são os elementos da linha n 
    do Triangulo de Pascal. 
 3) Escrevendo os termos do desenvolvimento na ordem acima(isto é, ordenando 
    segundo as potencias decrescentes de x), o termo de ordem k+1 é:
        Tk+1 = (Combinação n por k) (a**k)(x**n-k)
