\section{Introdução a Estatística}
    \subsection{O que é a estatística?}
    \begin{itemize}
        \item A Estatística envolve a coleta, organização, análise, interpretação 
        e apresentação de dados.
        \item Seu propósito central é extrair conhecimento dos dados disponíveis.
        \item Finalidade: apoiar a tomada de decisões fundamentadas em evidências.
        \item Fornece técnicas para resumir informações, identificar padrões e 
        compreender tendências.
    \end{itemize}
    \subsection{Conceitos fundamentais}
    \begin{itemize}
        \item A estatistica envolve a coleta, organização, análise, interpretação 
        e apresentação de dados
        \item Seu proposito central é extrair conhecimento 
        \item População: Conjunto completo de elementos investigados
        \item Amostra: Subconjunto representativo da população
        \item Variável de interesse: Caracteristica observada em cada indivíduo 
        da amostra, que será analisada estatisticamente
    \end{itemize}
    \subsection{Etapas da Análise Estatística}
    \begin{enumerate}
        \item Definir a população de interesse
        \item Estabelecer objetivos de pesquisa: investigar hipóteses, comparar 
        grupos ou descrever fenômenos
        \item Coleta de dados: por experimentos, questionários, observações ou 
        fontes existentes
        \item Organização dos dados: tabelas ou planilhas para facilitar análise
        \item Análise dos dados:
        \begin{itemize}
            \item Análise exploratória: compreensão inicial via gráficos e tabelas
            \item Análise inferencial: tirar conclusões sobre a população
        \end{itemize}
    \end{enumerate}
    \subsection{Temas da Estatística}
    \begin{itemize}
        \item Estatística descritiva / análise exploratória
        \begin{itemize}
            \item Apresentação clara e concisa dos resultados via gráficos e 
            tabelas
        \end{itemize}
        \item Probabilidade:
        \begin{itemize}
            \item Ferramentas para lidar e quantificar a incerteza
        \end{itemize}
        \item Inferência estatística:
        \begin{itemize}
            \item Estimação dos parâmetros desconhecidos
            \item Formulação e teste de hipóteses
            \item Generalização dos resultados da amostra para a população
        \end{itemize}
    \end{itemize}

\section{Organização dos Dados e Tipos de Variáveis}
    \subsection{Tipos de Variáveis}
    \begin{enumerate}
        \item Variáveis Qualitativas
        \begin{itemize}
            \item Definição: Descrevem categorias ou atributos e não representam 
            medidas numéricas.
            \begin{itemize}
                \item Nominais:
                \begin{itemize}
                    \item Não possuem ordem natural
                    \item As categorias apenas identificam grupos
                    \item Exemplos: Sexo, estado civil, tipo sanguíneo, cor dos 
                    olhos, \dots
                \end{itemize}
                \item Ordinais:
                \begin{itemize}
                    \item Possuem uma ordem ou hierarquia
                    \item A distância entre categorias não é conhecida
                    \item Exemplos: Escolaridade, grau de satisfação, faixas de 
                    judô, medalhas olímpicas, \dots
                \end{itemize}
            \end{itemize}
        \end{itemize}
        \item Variáveis Quantitativas
        \begin{itemize}
            \item Definição: Representam quantidades numéricas obtidas por 
            medição ou contagem
            \begin{itemize}
                \item Contínuas:
                \begin{itemize}
                    \item Obtidas por medição
                    \item Podem assumir qualquer valor dentro de um intervalo
                    \item Exemplos: Altura, peso, temperatura, pressão arterial, 
                    \dots
                \end{itemize}
                \item Discretas:
                \begin{itemize}
                    \item Obtidas por contagem
                    \item Assumem valores separados (geralmente inteiros)
                    \item Exemplos: Números de filhos, de acidentes, de veículos, 
                    de consultas, \dots
                \end{itemize}
            \end{itemize}
        \end{itemize}
    \end{enumerate}
    \begin{scriptsize} 
    Observação: A classificação depende da forma como a variável é medida ou 
    registrada, e não apenas do seu nome.
    \end{scriptsize}

    \subsection{Organização dos Dados}
    \begin{itemize}
        \item A organização de uma base de dados é crucial para garantir 
        eficiência na manipulação e análise das informações. Siga as etapas 
        abaixo
        \begin{enumerate}
            \item Defina claramente o objetivo da base de dados: isso orientará 
            as informações a serem armazenadas e a estrutura a ser adotada
            \item Utilize planilhas eletrônicas (Excel, Google Planilhas, Bloco 
            de Notas, etc.) para facilitar a organização e o acesso aos dados.
            \item Descreva detalhadamente cada variável, especialmente se 
            utilizar siglas ou abreviações, para garantir clareza e evitar 
            ambiguidades.
        \end{enumerate}
    \end{itemize}
    \subsubsection{Estrutura de uma Base de Dados}
    \begin{itemize}
        \item Uma base de dados pode ser representada como uma matriz:
        \[ x = 
        \begin{pmatrix}
            x_{11} & x_{12} & \cdots & x_{1p} \\
            x_{21} & x_{22} & \cdots & x_{2p} \\
            \vdots & \vdots & \ddots & \vdots \\
            x_{n1} & x_{n2} & \cdots & x_{np} \\
        \end{pmatrix}
        \]
        \begin{itemize}
            \item Cada linha representa uma observação (ou repetição do 
            experimento)
            \item Cada coluna representa uma variável
            \item $n$ é o número de observações
            \item $p$ é o número de variáveis medidas
            \item O elemento $x_{ij}$ representa o valor da variável $j$ na 
            observação $i$
        \end{itemize}

        \item Uma base de dados pode ser organizada em forma de tabela:
        \begin{table}[H]
            \centering
            \begin{tabular}{c|c|c|c}
                Aluno & Idade & Altura (cm) & Peso (kg) \\ \hline
                1 & 20 & 170 & 68 \\
                2 & 22 & 175 & 72 \\
                3 & 19 & 168 & 65 \\
                4 & 21 & 180 & 80 \\ \hline
            \end{tabular}    
        \end{table}
        \begin{itemize}
            \item Cada linha representa uma observação (ou indivíduo)
            \item Cada coluna representa uma variável
            \item Matemáticamente, essa base de dados pode ser representada 
            como uma matriz:
            \[ x = 
            \begin{pmatrix}
                20 & 170 & 68 \\
                22 & 175 & 72 \\
                19 & 168 & 65 \\
                21 & 180 & 80 \\
            \end{pmatrix}
            \]
        \end{itemize}
    \end{itemize}

    \subsubsection{De onde vêm os dados?}
    \begin{enumerate}
        \item Fontes Primárias:
        \begin{itemize}
            \item Dados coletados pelo próprio pesquisador para responder uma 
            pergunta específica
            \item Exemplos: Questionários, entrevistas, experimentos, observação 
            direta
        \end{itemize}
        \item Fontes Secundárias:
        \begin{itemize}
            \item Dados já existentes, produzidos anteriormente para outros 
            objetivos.
            \item Exemplos: IBGE, DataSUS, prontuários, artigos científicos, 
            big data
        \end{itemize}
    \end{enumerate}
    \begin{itemize}
        \item Conceitos Fundamentais
        \begin{itemize}
            \item Pesquisa: Processo sistemático de coleta, organização, análise 
            e interpretação de dados para responder a uma pergunta científica
            \item População: Conjunto completo de indivíduos ou unidades sobre 
            os quais desejamos obter informações
            \item Amostra: Subconjunto da população utilizado para realizar o 
            estudo e tirar conclusões sobre o todo
        \end{itemize}
    \end{itemize}
    

\section{Análise Exploratória de Dados}
    \subsection{População e Amostra}
    \begin{itemize}
        \item População -- Conjunto completo de individuos ou unidades de 
        interesse sobre os quais queremos obter informações.
        \item Amostra -- Subconjunto selecionado da população, usado para obter 
        informações e tirar conclusões sobre ela.
        \item Unidade Amostral -- Cada elemento individual da amostra. Unidade 
        sobre a qual as observações ou medições são realizadas.
    \end{itemize}

    \subsection{Amostragem}
    \begin{itemize}
        \item Probabilística
        \begin{itemize}
            \item Envolve seleção aleatória, garantindo que cada elemento da 
            população tenha uma chance conhecida de ser incluído na amostra
            \item Considerado um método científico rigoroso para coleta de dados
        \end{itemize}
        \item Não Probabilística
        \begin{itemize}
            \item Depende da escolha deliberada dos elementos pelo pesquisador, 
            baseada em critérios e julgamento, sem garantia de representatividade 
            estatística
        \end{itemize}
    \end{itemize}

\subsubsection{Métodos de Amostragem}
\begin{itemize}
    \item Aleatória Simples
    \begin{itemize}
        \item Definição: Todos os elementos da população possuem a mesma 
        probabilidade de serem selecionados
        \item Como realizar:
        \begin{itemize}
            \item Numere todos os elementos da população
            \[U=\{1,2,3,\dots,N\}\]
            \begin{scriptsize}

                $N$: Número de unidade amostral da população \\
                $n$: Número de unidade amostral de amostras
            \end{scriptsize}
        \end{itemize}
        \item O sorteio pode ser:
        \begin{itemize}
            \item Com reposição: o elemento retorna à população e pode ser 
            sorteado novamente
            \begin{itemize}
                \item Número de amostras possíveis: $N^n$, logo:
                \[
                P(U = u_i) = \frac{1}{N^n}
                \]
            \end{itemize}
            \item Sem reposição: o elemento não retorna e não poderá ser 
            selecionado novamente
            \begin{itemize}
                \item Número de possiveis amostras:
                \[
                C(N, n) = \left(\begin{array}{c} N \\ n \end{array}\right)
                = \frac{N!}{n!(N-n)!}
                \]
                logo,
                \[
                P(U = u_i) = \frac{1}{\left(\begin{array}{c} N \\ n \end{array}\right)}
                \]
                \item Observação: Uma combinação é uma seleção não ordenada de 
                elementos
            \end{itemize}
        \end{itemize}
        \item Vantagens: 
        \begin{itemize}
            \item Simples de aplicar
            \item Permite medir a precisão das estimativas
            \item Propriedades estatísticas bem conhecidas
        \end{itemize}
        \item Desvantagens:
        \begin{itemize}
            \item Requer lista completa da população
            \item Pode ser caro se a amostra for muito dispersa
            \item Não utiliza informações auxiliares
        \end{itemize}
        \item Qual deve ser o tamanho da amostra?
        \begin{itemize}

        \end{itemize}
    \end{itemize}
    \item Sistemática
    \begin{itemize}
        \item Definição: Os elementos da população estão ordenados, e a seleção 
        da amostra é realizada em intervalos regulares
        \item Etapas:
        \begin{enumerate}
            \item Defina o tamanho da população ($N$)
            \item Defina o tamanho da amostra ($n$)
            \item Calcule o intervalo da seleção ($IS$)
                \[IS = \frac{N}{n}\]
            \item Escolha aleatoriamente o primeiro elemento entre 1 e $IS$
            \item Selecione os demais elementos adicionado sucessivamente o 
            intervalo $IS$
        \end{enumerate}
    \end{itemize}
    \item Estratificada
    \begin{itemize}
        \item Definição: Divisão da população $U$ em $H$ grupos disjuntos e 
        homogêneos, conhecidos como estratos. Entre os estratos, existem 
        diferenças significativas, evidenciando a heterogeneidade da população
        \item Passos do procedimento:
        \begin{enumerate}
            \item Selecionar uma amostra dentro de cada estrato, de forma 
            independente
            \item Formar a amostra final unindo todas as amostras selecionadas 
            nos estratos
            \item Dentro de cada estrato, podem ser usados diferentes métodos 
            de coleta ou amostragem, conforme necessário
        \end{enumerate}
    \end{itemize}
